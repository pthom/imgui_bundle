# Dear ImGui Bundle: the demos

The demos of the catalog, by category: what each one shows, the libraries it uses, and its code on GitHub (Python, and C++ when it exists). Read the code of a demo close to what you write. Most demos run in the browser: https://imgui-bundle.pages.dev/playground/?demo=<file name> (not those marked desktop only). The guide for AI assistants: https://imgui-bundle.pages.dev/llms.txt; the API in plain text: https://imgui-bundle.pages.dev/llms/api/index.txt.


## Start here

The bundle in ten minutes: what it is, first apps, and a few lines that do a lot.
Read the code of a few of them: it gives the feel of the framework.

- What is an Immediate GUI: With Dear ImGui, your GUI code is simple and direct: no widget trees, no callbacks, no state synchronization. You call functions to create widgets, and they return the current value. That's it.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/welcome_imm_mode.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/welcome_imm_mode.cpp
- Hello world, in two lines: ImmApp opens the window, runs the loop, and calls your GUI function at every frame: immapp.run(gui) is all it takes. Add widgets to that function, and you have an app. The C++ version is three lines.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_hello_world.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_hello_world.cpp
- A parametric curve: Turn the knobs, or click Random: the curve follows at once. At every frame, the GUI function draws the plot with ImPlot and the knobs with imgui-knobs, and reads their values right there. No callbacks, no widget objects: that is the immediate mode.
  Uses: ImPlot, knobs
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_parametric_curve.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_parametric_curve.cpp
- A plot and markdown, in a few lines: A cosine wave moves in an ImPlot plot, under a text written in markdown. Both are add-ons, activated in one call: immapp.run(gui, with_implot=True, with_markdown=True). A good start for a small app.
  Uses: ImPlot
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_implot_markdown.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_implot_markdown.cpp
- Assets and add-ons: Load images and icons from your assets folder, and use two add-ons: markdown and ImPlot. A markdown editor with a live preview, and a pie chart whose values you can drag. Tick More info under each part to see how it is done. The add-ons are activated with immapp.AddOnsParams.
  Uses: ImPlot
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_assets_addons.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_assets_addons.cpp
- A beating heart: A heart curve drawn with ImPlot beats at the rate set by a knob from imgui-knobs. A few lines of Python: a parametric curve, scaled by a pulse at each frame. Turn the knobs to change the heart rate, or its thickness.
  Uses: ImPlot, knobs
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/haiku_implot_heart.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/haiku_implot_heart.cpp
- Butterfly effect, in a few lines: Two trajectories of the Lorenz system start almost at the same point, then drift apart: chaos in action. Drawn in 3D with ImPlot3D. Sliders change the system's parameters and the gap between the two starting points; Reset starts them over.
  Uses: ImPlot3D
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/haiku_butterfly.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/haiku_butterfly.cpp

## Build an app

  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/layout_docking.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/layout_docking.cpp
- A full app: docking, fonts, logs: A template for a real application, built with Hello ImGui: copy it and start from there. Dockable windows with several layouts, colored fonts and emojis, a log window, a status bar, toolbars, menus and a theme chooser. Your settings are saved, and restored at the next start. The code is heavily commented.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_docking.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_docking.cpp
- Custom 3D background (OpenGL) (desktop only): Draw anything behind your GUI with OpenGL: here, an animated sea whose waves and colors you can tune. The Seascape shader is by Alexander Alekseev (TDM, 2014). Hello ImGui calls runner_params.callbacks.custom_background at each frame, before the GUI: that is where it draws, with OpenGL (PyOpenGL in Python).
  Uses: OpenGL
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_custom_background.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_custom_background.cpp
- Power save when idle: When nothing happens, Hello ImGui lowers the frame rate to spare the CPU: after 3 seconds, the live plot and the spinner become choppy. Content that changes on its own says so with hello_imgui.set_item_is_live(), and keeps the full speed while it is visible. The idling settings are global.
  Uses: ImPlot, toggles, spinners
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_powersave.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_powersave.cpp
- Chinese and other non-Latin fonts (desktop only): The bundled fonts cover Latin, Greek and Cyrillic only: other scripts show up as ???. The fix: load a font that has the glyphs you need, first, so that it becomes the default font. This demo shows how, with Noto Sans SC: download it, and the demo's sample lines come alive.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_chinese_font.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_chinese_font.cpp
- Drag and drop: Drag a name onto another button to copy it, move it, or swap the two: the radio buttons pick the mode. Each button is both a drag source and a drop target. Adapted from the drag and drop section of the Dear ImGui demo.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_drag_and_drop.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_drag_and_drop.cpp
- Command palette: A searchable list of commands, as in VS Code: press Ctrl+Shift+P (Cmd+Shift+P on macOS). Type a few letters to filter it. One command changes the theme in two steps, another writes to the log below. Learn how to register commands and their callbacks with imgui-command-palette.
  Uses: command palette
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_command_palette.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_command_palette.cpp
- Test engine: Watch a ImGui Test Engine drive the mouse and the keyboard: it clicks buttons, types text, etc., and checks the results. For scripted runs on top of it (automated tests, pictures, an AI agent at the mouse), see the immapp.testing demo. See the test engine doc.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_testengine.py
  C++: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_cpp/demos_immapp/demo_testengine.cpp
- immapp.testing: scripted runs (desktop only): Easy automated tests with immapp.testing, a thin layer on the test engine: a script drives the app, then exits. The test engine demo shows the engine itself. Here, a test function drives the GUI (it clicks, moves a slider, opens a header) and captures a picture at each step; immapp.testing.run() starts the app, runs the test, then exits. The same recipe gives documentation pictures, and lets an AI agent see and drive the app it writes, with nobody at the mouse (the bundle's screenshot skills are built on it). See the test engine doc.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_immapp_testing.py

The libraries in the bundle: full demos, widget tours, showcases.

## Python specifics

Async, Matplotlib, Pydantic, context managers, and pure Python backends.

- Context managers (imgui_ctx): In Python, with imgui_ctx.begin("Window"): replaces a begin() / end() pair, and the end() can no longer be forgotten. The same exists for child windows, menus, popups, tables, tabs, fonts and styles, and for ImPlot with implot_ctx. Open a section to try it and read its code. See the Python tips.
  Uses: ImPlot
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_python_context_manager.py
- Run code alongside the GUI (async) (desktop only): The GUI runs as an asyncio task, while a Python loop keeps computing. The window shows both rates: the GUI's frames per second, and the loop's computations per second. The loop yields with await asyncio.sleep(0) to share the event loop. See async support.
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_run_async.py
- A GUI beside a Jupyter notebook (desktop only): A GUI that stays open beside a Jupyter notebook while its cells run. Change a variable in a cell, and the plot follows; train a model, and tune it while it learns. The page explains the two modes (blocking, and immapp.nb.start() that returns at once); its video trains a neural network live, its learning rate on a slider.
  Uses: ImPlot
  Page: https://imgui-bundle.pages.dev/doc/python/notebook-runners/
  Video: https://www.youtube.com/watch?v=VqLz5F_bk60
- Control the GLFW window (desktop only): glfw_utils.glfw_window_hello_imgui() returns the GLFW window that Hello ImGui created. With it, any function of pyGLFW works on your app's window. Here, buttons maximize, restore, minimize or center it, a slider sets its opacity, and another button makes it ask for attention in the taskbar.
  Uses: GLFW
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/demos_immapp/demo_glfw_window_manip.py
- Matplotlib figures: imgui_fig.fig() shows a Matplotlib figure as an image in the GUI. On the left, an animated sine wave, redrawn at each frame, with a slider for its amplitude. On the right, a static figure, drawn once. Handy to reuse existing Matplotlib code; for fast interactive plots, prefer ImPlot.
  Uses: Matplotlib

## Interactive science

Explorable lessons in physics, chaos and machine learning, built with the bundle.
Dear ImGui Bundle excels at real-time scientific visualization: 60 frames per second or more, even under load. These demos show it.

- Interactive exploration of the Mandelbrot set: Click a point of the Mandelbrot set to see its Julia set. Fly to famous values of c, and zoom into both pictures: near each point, the two sets look alike.
  Uses: ImmVision
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/playground/examples/explorables/julia_map/julia_map.py
- A tiny neural network learns two spirals: Can 16 neurons tell two spirals apart? Watch a tiny neural network) learn, live, as in the TensorFlow Playground. Then read how it works, formula by formula, next to its numpy code.
  Uses: ImPlot
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/playground/examples/explorables/neural_spiral/neural_spiral.py
- Simple harmonic motion: A mass on a spring, a pendulum, a vibrating string: they all follow the same equation. It is the equation of simple harmonic motion (for the pendulum, at small angles). Adjust the mass and the spring stiffness, and watch how the motion changes.
  Uses: ImPlot, knobs
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/playground/examples/explorables/lesson_harmonic_motion.py
- Double pendulum: A double pendulum is a chaotic system: tiny changes in its initial conditions lead to wildly different trajectories. Drag the angles to set initial positions, then release and watch chaos unfold.
  Uses: ImPlot, knobs, toggles
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/playground/examples/explorables/double_pendulum.py
- Fourier epicycles: Any closed curve can be approximated by a sum of rotating circles (a Fourier series). Adjust the number of circles to see how the approximation improves.
  Uses: ImPlot, knobs, toggles
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/playground/examples/explorables/fourier_epicycles.py
- Boids (flocks): A flock of birds emerges from three simple local rules, with no leader and no plan. Each bird stays apart from its neighbors (separation), flies their way (alignment), and stays with them (cohesion). This is the boids model of Craig Reynolds (1986).
  Uses: ImPlot, knobs, toggles
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/playground/examples/explorables/boids.py
- Logistic map: A very simple equation, and yet it can lead to wildly different behaviors, up to chaos. The logistic map, x(n+1) = r * x(n) * (1 - x(n)), models for example the growth of a population with limited resources. Depending on r, it is stable, periodic (in 2-cycles, 4-cycles, etc), or chaotic. Let's explore this.
  Uses: ImPlot, toggles
  Python: https://github.com/pthom/imgui_bundle/blob/main/bindings/imgui_bundle/demos_python/playground/examples/explorables/logistic_map.py
